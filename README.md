## About

This is a simple GitHub Pages site showcasing my work and projects.

## Technologies Used

- HTML5
- CSS3
- Javascript

## Getting Started

To view the site locally:

1. Clone the repository
2. Open `index.html` in your browser

The site is automatically deployed via GitHub Pages. Run the workflow `pages-build-deployment` to deploy any changes to the pages.
